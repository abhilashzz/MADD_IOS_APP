## Instructions for Capturing Screenshots

### When Running in macOS Xcode / Swift Playgrounds:
1. Open the Swift file or copy its content into an Xcode Playground.
2. Run the code by pressing the blue Run button (or Shift + Return).
3. Capture a clear screenshot of the console / sidebar output area showing the printed results.
4. Save the screenshot under the exact filenames listed above inside this `screenshots/` directory.

### When Running on Windows via Swift CLI:
1. Open PowerShell and run:
   ```powershell
   .\Run-All.ps1
   ```
2. Capture a screenshot of the PowerShell terminal showing the program header and execution output.
3. Save the images in this directory under `01-Collections.png`, `02-Control-Flow.png`, and `03-Final-Challenge.png`.
